
# Rock Paper Scissors 🪨📄✂️
A lightweight, browser-based implementation of the classic Rock, Paper, Scissors game, built using **HTML**, **CSS**, and **JavaScript**. 
Challenge the computer and test your luck!

🔗 Live [Demo](https://mariog-03.github.io/Rock-Paper-Scissors/) — play the game now.

## Features
- Classic Rock, Paper, Scissors gameplay against the computer
- Instant win/lose/tie feedback
- Running score tracker
- Clean, responsive UI
- No external libraries or dependencies — pure HTML/CSS/JS

## Built With
- **HTML5** – structure and markup
- **CSS3** – styling and layout
- **JavaScript (Vanilla)** – game logic and interactivity

## Prerequisites
You just need a modern web browser — no installations required.

## How to Play
1. Click on Rock, Paper, or Scissors.
2. The computer randomly selects its move.
3. The winner is determined using classic rules:
   - Rock beats Scissors
   - Scissors beats Paper
   - Paper beats Rock
4. The result and updated score are displayed on screen.
